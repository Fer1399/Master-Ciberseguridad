# Análisis de activos, amenazas, vulnerabilidades, riesgos y medidas de seguridad

## Ejemplo 1. Servidor corporativo

| Elemento                 | Descripción                                                                                                                                |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **Activo**               | Servidor corporativo que almacena documentos y datos de la empresa.                                                                        |
| **Amenaza**              | Ataque de ransomware que cifra los archivos del servidor.                                                                                  |
| **Vulnerabilidad**       | Sistema operativo sin actualizar y con vulnerabilidades conocidas.                                                                         |
| **Riesgo**               | Pérdida de acceso a los datos, interrupción de los servicios y posibles pérdidas económicas.                                               |
| **Medidas de seguridad** | Mantener el sistema actualizado, utilizar un antivirus o EDR, restringir los permisos de acceso y realizar copias de seguridad periódicas. |

## Ejemplo 2. Equipo informático de un empleado

| Elemento                 | Descripción                                                                                                                                           |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Activo**               | Ordenador de un empleado con acceso a los sistemas corporativos.                                                                                      |
| **Amenaza**              | Infección por malware mediante un archivo adjunto malicioso.                                                                                          |
| **Vulnerabilidad**       | Falta de formación en ciberseguridad y ejecución de archivos de origen desconocido.                                                                   |
| **Riesgo**               | Robo de credenciales, exposición de información confidencial y propagación del malware por la red corporativa.                                        |
| **Medidas de seguridad** | Formar a los empleados, filtrar el correo electrónico, utilizar herramientas EDR, actualizar el software y aplicar el principio de mínimo privilegio. |

## Ejemplo 3. Página web corporativa

| Elemento                 | Descripción                                                                                                                                                                      |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Activo**               | Página web corporativa que ofrece información y servicios a los clientes.                                                                                                        |
| **Amenaza**              | Ataque de inyección SQL contra la aplicación web.                                                                                                                                |
| **Vulnerabilidad**       | Validación insuficiente de las entradas del usuario y consultas SQL construidas de forma insegura.                                                                               |
| **Riesgo**               | Acceso no autorizado a la base de datos, modificación de información o exposición de datos de clientes.                                                                          |
| **Medidas de seguridad** | Utilizar consultas parametrizadas, validar las entradas, actualizar el CMS y sus complementos, realizar auditorías de seguridad y aplicar un firewall de aplicaciones web (WAF). |

## Ejemplo 4. Base de datos de clientes

| Elemento                 | Descripción                                                                                                                                                                 |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Activo**               | Base de datos que contiene información personal de los clientes.                                                                                                            |
| **Amenaza**              | Acceso indebido o extracción de información por parte de un atacante o usuario no autorizado.                                                                               |
| **Vulnerabilidad**       | Permisos excesivos, credenciales débiles o base de datos expuesta a Internet sin controles adecuados.                                                                       |
| **Riesgo**               | Filtración de datos personales, daños reputacionales y posibles sanciones legales.                                                                                          |
| **Medidas de seguridad** | Aplicar el principio de mínimo privilegio, utilizar autenticación robusta, cifrar los datos, registrar los accesos y restringir las conexiones mediante reglas de firewall. |

## Ejemplo 5. Servicio de correo electrónico corporativo

| Elemento                 | Descripción                                                                                                                                                         |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Activo**               | Cuentas de correo electrónico utilizadas para las comunicaciones profesionales.                                                                                     |
| **Amenaza**              | Ataque de phishing para robar las credenciales de los empleados.                                                                                                    |
| **Vulnerabilidad**       | Ausencia de autenticación multifactor (MFA) y falta de mecanismos adecuados de detección de correos fraudulentos.                                                   |
| **Riesgo**               | Suplantación de identidad, acceso no autorizado al correo y utilización de la cuenta para distribuir nuevos ataques.                                                |
| **Medidas de seguridad** | Activar MFA, implantar filtros antiphishing, formar a los empleados y configurar SPF, DKIM y DMARC para mejorar la protección frente a la suplantación del dominio. |

---

## Conclusión

El análisis de riesgos permite identificar los activos que deben protegerse, las amenazas que pueden afectarlos y las vulnerabilidades que podrían facilitar un incidente de seguridad.

La aplicación de medidas preventivas, técnicas y organizativas ayuda a reducir la probabilidad de que se materialicen las amenazas y a minimizar su impacto sobre la **confidencialidad, integridad y disponibilidad (CID)** de la información.
